# UOS 1070 ARM64 DEB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and deliver a native ARM64 Debian package of DSH Desktop for UnionTech UOS Desktop Professional 1070 on Kirin 990.

**Architecture:** Extend the verified amd64 packaging path with an explicit ARM64 package command, a dual-architecture verifier, a native Debian 10 ARM64 container, and a GitHub Actions job on `ubuntu-24.04-arm`. Keep the existing amd64 command and artifact unchanged, and reject any package whose Debian metadata or main ELF architecture does not match `arm64`/AArch64.

**Tech Stack:** Electron Builder 26, Electron 43, Node.js 22.20.0, Vitest, Bash, Debian 10, Docker BuildKit, GitHub Actions

---

- Modify `package.json`: add the Linux ARM64 packaging command without changing the amd64 command.
- Modify `test/release.test.ts`: define the ARM64 package, verifier, container, and workflow contracts before implementation.
- Modify `scripts/verify-linux-deb.sh`: accept an expected Debian architecture and verify the matching ELF machine.
- Create `build/linux-arm64.Dockerfile`: build, verify, install, and launch the application in native Debian 10 ARM64.
- Create `.github/workflows/uos-arm64-deb.yml`: run tests and the native ARM64 package job, then upload the verified artifact.
- Create `outputs/dsh-desktop-linux-arm64.deb.sha256`: final downloaded artifact checksum; generated only after CI succeeds.

deb_path="${1:?Usage: scripts/verify-linux-deb.sh <package.deb> [amd64|arm64]}"

  amd64) elf_machine='Advanced Micro Devices X86-64' ;;

    ;;
